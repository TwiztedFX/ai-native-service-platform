# Code of conduct

People working on Outcome OS are expected to:

- discuss the work directly and specifically
- keep credentials, customer data, and session tokens out of issues, commits, and logs
- treat security reports as private until a fix exists
- leave review comments about the code and the decision, not about the person

Maintainers may close or revert contributions that ignore those rules. For a vulnerability, follow `SECURITY.md` instead of a public issue.
